# BankAccSetup-ChatBox
A conversational chatbot to assist with bank account setup. Built in Python, this project provides a web interface, models, and controllers to guide users through the process, collecting and validating needed information.

# Features:
    -Interactive chat UI allowing users to input required data (e.g., personal info, account type).
    -Data validation and error feedback.
    -Web server / front-end integration.
    -Modular design (controllers, models, web) to facilitate maintainability and extension.



# Prerequisites
    -Python 3.x
    -A modern browser (if there is a front-end)
    -(Optional) virtual environment tool (VSCode, conda, etc.)

# Installation
Clone the repository:

    git clone https://github.com/simzta/BankAccSetup-ChatBox.git
    cd BankAccSetup-ChatBox

Install dependencies:

    pip install -r requirements.txt
    If there’s no requirements.txt, install packages listed in package-lock.json / manually as needed.
